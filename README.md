[Download the Application](https://manichaean-ground642.github.io)

## 📖 About this tool

This tool processes scanned PDF files. Many PDFs consist of images rather than text. Computers cannot search inside images. This software uses OCR, or Optical Character Recognition, to read those images. It converts the visual data into searchable text. You can process thousands of files in one batch. Once the process finishes, you search your documents for specific keywords.

## 🛠 System requirements

Ensure your computer meets these standards before you begin:

* Windows 10 or Windows 11.
* At least 8GB of RAM. Processing large batches requires memory.
* 500MB of free disk space for the program installation.
* A stable processor. Multi-core processors speed up the OCR process significantly.

After the initial scan, you search your documents through the search bar:

1. Type your desired keyword into the search field.
2. Press Enter or click the Search button.
3. The tool generates a list of files containing the keyword.
4. Click any file in the list to open it.
5. The application highlights the instances where the text appears.

## ⚙️ Settings and preferences

You adjust the performance of the tool in the Settings menu:

* OCR Quality: Choose between speed and accuracy. High accuracy takes more time but reads handwriting better.
* Output Location: Choose where your index files go. Keeping them on a fast drive improves performance.
* File Filtering: Choose to ignore specific file types if you only want to process PDF files.

## 🤝 Troubleshooting common issues

If you face problems, review these solutions:

* Software does not start: Check if you have the latest drivers for your graphics card or Windows updates.
* OCR takes too long: Reduce the number of files in your folder. Process large batches in smaller groups.
* Search returns no results: Ensure the OCR process finished for those specific files. Check that you spelled your search term correctly.
* Application freezes: The computer may run low on memory. Close background applications to free up resources.
* Missing text in search: High-resolution images provide better results. Ensure your scans are at least 300 DPI.

## 📋 Data privacy

This software performs all tasks locally on your computer. It does not send your documents or data to a server. Everything stays on your hard drive. Your information remains private throughout the process.

## 💡 Best practices for clear results

The quality of your search depends on the quality of your source files. Follow these tips to get the best results:

* Use clear, high-contrast scans.
* Straighten tilted pages before scanning if possible.
* Remove staples or paperclips that create shadows on the page.
* Group files by document type. 
* Avoid scanning very faint pencil marks.
